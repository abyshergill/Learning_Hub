## Chapter 4: The Global Toy Store (Docker Hub)

You don't always have to write your own recipes. What if you want a Lego castle that someone else already designed?

You go to **Docker Hub**.

Docker Hub is a giant, free online toy store where developers from all over the world share their pre-made Docker Images. If you need a database, a web server, or a Minecraft server, you don't build it. You just open your computer terminal and type:

`docker pull minecraft-server`

Boom! The recipe downloads instantly, ready for you to bake.
