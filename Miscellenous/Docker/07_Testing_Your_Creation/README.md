## Chapter 8: Testing Your Creation



Now for the best part. Let's walk through the secret hallway!



1. Open your favorite web browser (like Chrome, Safari, or Edge).

2. In the address bar where you normally type website names, type this exactly: `http://localhost:8080`

3. Press Enter.



**Boom!** You should see a white screen that says: **"Welcome to nginx!"** You are now officially hosting a live web server on your own machine inside an isolated container. If you want to stop this invisible container from running, you just look up its ID using `docker ps` and type `docker stop <CONTAINER_ID>`.
